# Visual Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the whole site in the dark-navy / bright-blue, photo-led direction of the ChatGPT concept, keeping Koba's logo, all content, SEO and tests, and add an About page.

**Architecture:** New design tokens in `global.css`; a shared `PhotoHero.astro` used by home, service, business and about pages; photos in `src/assets/photos/` served through Astro `<Image>`; a `mtavruli()` helper for eyebrow labels. Existing components are restyled in place, not rewritten. Tests keep running against `dist/`.

**Tech Stack:** Astro 7 (`astro:assets` + sharp), Noto Sans Georgian, Node `node:test`, puppeteer-core for photo sourcing and screenshots (scratchpad only, not a project dependency).

**Spec:** `docs/superpowers/specs/2026-09-28-redesign-design.md`

## Global Constraints

- Colours: navy-950 `#0B1420`, navy-900 `#111C29`, ink `#152233`, blue-500 `#1E7BFF`, blue-600 `#1766D6`, mist `#F3F6F9`, white, line `#DCE3EA`; fire/ice/water only on service icons.
- Koba's real logo (`src/assets/emblem.png`) and name ნისეკომპანი; never the concept's "N" logo.
- Photos only from Pexels/Unsplash free licence, recorded in `src/assets/photos/CREDITS.md`; never the TAME Group images from the saved ChatGPT page.
- H1/H2 stay Mkhedruli; Mtavruli only for short eyebrow labels.
- No prices, no invoices, no experience claims, Georgian only.
- Every existing test keeps passing; Lighthouse ≥ 95 in all four categories; no horizontal scroll 360–1920px.

## Review Focus

1. Hero text contrast over photos — white text must stay ≥ 4.5:1 against the darkest-to-lightest part of the photo under it (gradient overlay). Checked by Lighthouse accessibility + visual review at 390 and 1440.
2. LCP with a large hero photo on mobile — must stay ≥ 95 performance (responsive widths, AVIF/WebP, `fetchpriority="high"`). Lighthouse on home at mobile.
3. Mtavruli rendering — labels must render with Noto Sans Georgian glyphs, not tofu boxes; the self-hosted font subset must include U+1C90–1CBF. Test in Task 1.
4. Sub-path build (`BASE_PATH=/nicecompany`) — new About page links and header "სერვისები" anchor carry the base. Existing sub-path test run in Task 6.
5. Mobile header with the new nav item — chip row scrolls inside itself; page never scrolls sideways (width sweep in Task 6).
